Mine

This starter wallet is a private chain on this computer. You are the only miner, so the buttons usually succeed. That is practice, not public FUC.

On the public chain, mining is a race: about every two minutes someone finds a block. The whole ~76 FUC goes to that finder. Pressing mine does not put you in a queue and does not guarantee the next block. Other people hash at the same time. A mining reward still needs 100 extra blocks before it can be spent.

Save a copy of your keys

BITFUC does not use a 12-word phrase. Your keys live in a wallet file on this computer. This copies that file so you can put it on a USB stick. Anyone who has the file can spend your coins. This website never sees it.

Close the tab anytime. Stop the node in a terminal with bitfuc-cli stop if you started it yourself.
