Independent verification

bitfucd is the system of record. If this website is withdrawn, a public chain (when one exists) does not depend on it.

cmake -B build -DENABLE_IPC=OFF -DBUILD_GUI=OFF -DINSTALL_MAN=OFF
cmake --build build --target bitcoind bitcoin-cli
./build/bin/bitfucd -regtest -daemon
./build/bin/bitfuc-cli -regtest getblockchaininfo

CMake targets remain bitcoind / bitcoin-cli; output names are BITFUC. Datadir is not Bitcoin’s (macOS: ~/Library/Application Support/Bitfuc).

Three-node acceptance: ./scripts/regtest/acceptance.sh — docs/regtest.md.

Regtest P2P / RPC: 17444 / 17443. Magic 96 79 32 83. Bitcoin 18444 / 18443 unused.

Seed lists are empty by design. Regtest peers are added with addnode.
