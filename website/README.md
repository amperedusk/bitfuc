# bitfuc.com (static)

Working-paper / prospectus layout. **Not a node, not a wallet, not an explorer backend.**
Not affiliated with MIT; “MIT license” is the license, not the institute.

Deploy **this directory only**. Do not point Vercel at the Bitcoin Core tree (`src/`, `depends/`).

```bash
cd website
npx vercel
```

Preview URL is enough. Production `bitfuc.com` can wait until a domain is attached.

If the explorer or DEX pages look unfinished: they are. Inventing a tip or an order book would violate the project rules.
